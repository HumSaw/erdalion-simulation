# Летопись Эрдалиона

[English version](README.md)

Эволюционная симуляция самообучения: 10 фэнтези-народов делят один континент и учатся выживать через войны, набеги, дипломатию, торговлю и династические браки. Их поведение никто не программирует — каждая фракция начинает с грубых инстинктов и корректирует стратегию по результатам собственных решений.

## Как устроено обучение

У каждой фракции — независимая табличная Q-функция над небольшим дискретным пространством состояний:

- **Состояние** — отношение к цели (`война / вражда / нейтралитет / дружба / союз`) × соотношение сил (`слабее / равные / сильнее`)
- **Действия** — война, набег, дипломатия, торговля, брачный союз, развитие
- **Обновление** — инкрементальное: `Q(s,a) += lr * (reward - Q(s,a))`
- **Исследование** — ε-жадная стратегия: ε стартует с 0.4 и затухает с коэффициентом 0.998 до пола 0.05

Начальные Q-значения засеяны «видовыми» приорами с шумом: агрессивные народы стартуют со склонностью к насилию, хитрые — к дипломатии. Награды считаются из конкретных исходов: захваченная территория, потери армии, доход от торговли, сдвиг отношений после дипломатии и браков.

Самое интересное — наблюдать, как агрессивные народы учатся тому, что нападать на сильных соседей невыгодно. Или не учатся — и исчезают с карты.

## Мир

- 10 народов с разными характеристиками: люди, огры, эльфы, тёмные эльфы, гномы, орки, нежить, народ глубин, зверолюды, драконорождённые
- Войны с разрешением сражений, передачей территорий и потерями
- Набеги, торговые соглашения, дипломатические миссии
- Династические браки, связывающие фракции
- Правители с возрастом, чертами характера и престолонаследием
- Летопись всех значимых событий, которая пишется по ходу симуляции

## Запуск

```bash
pnpm install
pnpm dev
```

Открыть http://localhost:3000. Симуляция полностью работает в браузере, бэкенда нет.
